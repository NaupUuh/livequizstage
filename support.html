What to include in your email

The faster we can reproduce a problem, the faster it gets fixed. Paste these details into your first message:

  • Your Windows version (for example, Windows 11 23H2, 64-bit) and the QuizStage version from the About screen.
  • Your OBS Studio version, if the issue involves the overlay.
  • What you expected to happen and what happened instead.
  • The exact text of any error message, copied rather than photographed if possible.
  • How many players were joining, and whether the phones were on the same Wi-Fi as the host laptop.
  • Your order number, if the question is about licensing or a refund.

Common setup questions

Players cannot open the join page

Confirm the phone is on the same Wi-Fi network as the host laptop — not on mobile data. Some venue routers enable "AP isolation" or "client isolation," which blocks devices from talking to each other even on the same network. Turn that setting off in the router, or use a travel router you control. Also check that Windows Firewall allowed QuizStage on private networks when it first started.

The OBS overlay is blank or shows an error

Add a Browser source in OBS Studio 28 or newer and set the URL to http://127.0.0.1:8899/ with a 1920×1080 canvas. QuizStage must be running while OBS captures the source. If the overlay loaded once and then went blank, right-click the source and choose Refresh.

My question pack will not import

Packs are CSV files. Save them as comma-separated values with UTF-8 encoding, keep the header row intact, and make sure every row has the same number of columns. Questions with commas inside them must be quoted. Excel and Google Sheets both export this format correctly.

Can I move my license to a new computer?

Yes. One license covers one host machine at a time, and you can move it when you replace that machine. Email us from the address used at checkout and we will reset the activation so you can install on the new laptop.

Can I run two shows on two laptops at once?

Each simultaneous host machine needs its own license. If you run multiple rooms at one event, buy a license per host laptop. Players never need a license of their own.

Does QuizStage need internet during a show?

No. The host app, the player join page, and the overlay server all run locally. Internet is only used for downloading the installer and updates, and for whatever you choose to stream to.

Not covered by support

We help with QuizStage itself: installation, activation, features, overlay output, and defects. We cannot troubleshoot your venue's router, general Windows problems unrelated to the app, OBS scenes beyond the browser source URL, or write and edit your quiz questions. For OBS configuration, the OBS Studio documentation and community forums are the right place to start.

What QuizStage is

A quiz engine for the room, not for the internet.

Most quiz tools are built for remote audiences and charge a monthly fee. QuizStage is the opposite: a single Windows application that runs the entire show on your machine, on your local network, with no accounts for you and no app installs for your players.

Host on your laptop

The show lives in one desktop window: questions, timer, scores, and player management.

Players use a phone browser

They type the join code at the local address you show on screen. No downloads, no sign-up.

Stream the overlay

Point an OBS browser source at the built-in overlay server and the leaderboard is broadcast-ready.

Everything stays local

Questions, answers, and scores never leave your laptop. The show keeps running with no internet.

How it works

From opening the app to a live show in four steps.

The whole setup is one laptop and one Wi-Fi network. Nothing to configure in the cloud, nothing to install on player devices.

Load a question pack

Use a built-in round or import your own questions from a CSV file. Rounds mix easy, medium, and hard questions in a fixed flow.

Start the lobby

QuizStage shows a short join code and a local address. Players on the same Wi-Fi enter it in their phone browser and pick a name.

Run the round

Advance through 15 questions. Everyone gets 3 lives — a wrong answer costs one, and players are out when their lives run out.

Stream and crown a winner

The overlay updates live in OBS with the top 60 players on the leaderboard. Read out the winner and start the next pack.

Requirements

What you need before showtime.

The host machine runs QuizStage and OBS. Players need nothing but a browser — no app, no account, no install.

Host machine

  • Windows 10 or Windows 11, 64-bit
  • A laptop or desktop on the same network as your players
  • Wi-Fi router or access point that supports client-to-client traffic
  • OBS Studio 28 or newer, recommended for streaming the overlay
  • No internet connection required during the show

Players

  • Any modern phone or tablet with a browser
  • Connected to the same Wi-Fi network as the host
  • The short join code shown on the host screen
  • No app install, no account, no email address

Streaming the overlay

  • Add a Browser source in OBS and point it at http://127.0.0.1:8899/
  • Set the source to 1920×1080 to match a standard stream canvas
  • Keep QuizStage running while OBS captures the overlay

FAQ

Questions before you buy.

How do players join the quiz?

QuizStage displays a join code and a local web address on the host screen. Players on the same Wi-Fi open that address in their phone browser, type the code, and choose a display name. There is nothing to install and no account to create.

Do I need an internet connection to run a show?

No. The host app, the player join page, and the overlay server all run on your laptop over the local network. Internet is only needed to download the installer and your updates, and to stream to a platform if you choose to.

How many players can join one game?

Up to 1,000 simultaneous players on a single host machine. In practice your Wi-Fi access point is the limiting factor — a consumer router handles a few hundred phones comfortably, and larger venues should use a dedicated access point.

How does the OBS overlay work?

QuizStage runs a local overlay server at http://127.0.0.1:8899/. In OBS Studio 28 or newer, add a Browser source pointing to that address at 1920×1080. The leaderboard, question, and timer graphics update live as the round progresses, and you can switch between the 5 themes from the host app.

Can I write my own questions?

Yes. Question packs are plain CSV files, so you can write them in Excel, Google Sheets, or any text editor and import them into QuizStage. Each round runs 15 questions in an easy, medium, hard flow, and you can keep as many packs as you like.

What happens when a player answers wrong?

They lose one of their 3 lives. Players keep answering until all three lives are gone, which keeps casual players in the room instead of knocking them out on question two.

Is this a subscription? Will it stop working after a year?

No. Starter is $15 and Pro is $39, both one-time, both for one host machine. Starter includes 6 months of updates, Pro includes 12. After that the version you already have keeps working indefinitely — nothing is disabled and there is no renewal requirement.

Can I install it on more than one computer?

One license covers one host machine. If you run shows from two laptops, or want a backup machine for events, you need a second license. You can move a license to a replacement machine by contacting support.
